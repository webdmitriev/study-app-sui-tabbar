# Study App — SwiftUI Custom TabBar

Учебный проект: кастомный TabBar в SwiftUI с дефолтным поведением для iPhone Duo.

## 🚀 Возможности

- Работа с кастомным TabBar
- Модификаторы
  - `AppConstants`
- Компоненты
  - `BlockHorizontalView`
  - `HeaderComponentView`

## 🛠 Технологии
